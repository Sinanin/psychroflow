# OG Image Required

Create a 1200x630px image named `og-image.png` and place it in this /public folder.

It will be used as the preview image when psychrostudio.com is shared on:
- LinkedIn
- Twitter / X
- WhatsApp
- Facebook

Recommended content:
- Dark navy background (#080E1A)
- PsychroStudio logo (PS mark + wordmark)
- Headline: "Engineering Intelligence for HVAC Professionals"
- The app preview mockup or a clean tagline
- psychrostudio.com URL at bottom

You can create this in Canva, Figma, or ask Claude to generate it.
